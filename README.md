# Flowbase — Modern SaaS Landing Page

A complete, production-quality single-page landing page for **Flowbase**, a fictional all-in-one productivity and workflow platform.

Built with **only HTML, CSS, and vanilla JavaScript** — no frameworks, no Tailwind, no external UI libraries.

Designed to look like a real SaaS product from a top-tier design team (inspired by Linear, Vercel, Notion, Stripe) — clean, fast, and deployable as-is.

![Flowbase Preview](preview.png)

---

### ✨ What’s Included

**Pages / Sections:**
- Sticky blurred navbar with mobile hamburger
- Hero with email capture + trust statement
- Full dashboard mockup built with HTML/CSS (no images)
- Social proof strip
- Problem / value proposition (4 cards)
- Features with alternating layout + real UI mocks
- Interactive automation builder (WHEN / IF / THEN)
- Analytics with pure CSS/SVG charts
- Testimonials
- Pricing with monthly/yearly toggle (functional)
- FAQ accordion (one-open-at-a-time)
- Final CTA + multi-column footer

**Interactions:**
- Mobile navigation
- Navbar scroll blur effect + active link tracking
- Smooth scrolling
- Email validation + toast notifications
- Pricing toggle that recalculates prices
- Automation builder conditional logic
- Animated counters (IntersectionObserver)
- Scroll reveal animations (respects `prefers-reduced-motion`)
- Keyboard accessible

### 🛠 Tech Stack

- HTML5 (semantic)
- CSS3 (variables, grid, flexbox, custom properties)
- Vanilla JavaScript (ES6+)
- Fonts: Inter + Geist via Google Fonts

**Zero dependencies.**
